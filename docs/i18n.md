# Internationalization (i18n)

**English** | [简体中文](#简体中文)

Metamorph documentation is maintained in multiple languages. GitHub shows `README.md` by default; other locales use the `README.<locale>.md` convention used by many high-star projects (Vue, Element Plus, Ant Design, etc.).

## Supported languages

| Locale | File | Status |
|--------|------|--------|
| `en` (default) | [`README.md`](../README.md) | ✅ Canonical |
| `zh-CN` | [`README.zh-CN.md`](../README.zh-CN.md) | ✅ |
| `ja` | `README.ja.md` | ⏳ Planned |
| `zh-TW` | `README.zh-TW.md` | ⏳ Planned |

Each localized README must include a language switcher in the header:

```markdown
**English** | [简体中文](README.zh-CN.md)
```

```markdown
[English](README.md) | **简体中文**
```

## Rules

1. **`README.md` is the source of truth** for structure and section order.  
2. Localized files should mirror the same headings (translated) so links stay parallel.  
3. Code blocks, CLI flags, package names, and env vars (`METAMORPH_*`) stay in English.  
4. Badges and absolute repo URLs stay identical across languages.  
5. When changing CLI / eval semantics, update **all shipped locales** in the same PR.  
6. Evaluation artifacts (`docs/EVAL.md`) may stay bilingual or English-primary; regenerate via `metamorph eval`.

## Adding a language

1. Copy `README.md` → `README.<locale>.md`
2. Translate prose; keep identifiers unchanged
3. Add the locale to the switcher on every README
4. Update this table

## Docs index

| Doc | Language policy |
|-----|-----------------|
| `README*.md` | Per-locale |
| `CONTRIBUTING.md` | Dual-language sections in one file |
| `docs/i18n.md` | This file (EN + ZH sections) |
| `docs/EVAL.md` | Generated scorecard (zh headings OK) |

## 简体中文

Metamorph 文档支持多语言。GitHub 默认展示 `README.md`；其他语言采用高星项目常见的 `README.<locale>.md` 约定。

### 已支持语言

| 语言 | 文件 | 状态 |
|------|------|------|
| 英语（默认） | [`README.md`](../README.md) | ✅ 权威版本 |
| 简体中文 | [`README.zh-CN.md`](../README.zh-CN.md) | ✅ |

### 约定

1. **以 `README.md` 为结构真源**，各语言章节顺序保持一致。  
2. 代码、CLI、包名、环境变量保持英文，不翻译。  
3. Badge 与仓库绝对 URL 各语言保持一致；`CONTRIBUTING.md` 用同一文件内中英双语章节。  
4. 修改用户可见语义时，同一 PR 更新所有已发布语言。  
5. 新增语言：复制 → 翻译 → 更新各 README 顶部语言切换 → 更新本表。
